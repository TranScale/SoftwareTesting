# Repository Instructions

## Final Submission Guardrail

- Use `$uef-final-report-guardian` for any task related to the final report, presentation, testing artifacts, defect evidence, submission packaging, or rubric compliance.
- Read `Report Test subject/UEF - Final.pdf` before giving substantive advice or generating deliverables for the final submission.
- Treat these deliverables as mandatory unless the user explicitly changes scope:
  - Main: `Word` report and `PPTX`
  - Link set: test cases in `Excel`, test script plus test data, final results in `Excel` plus images, automation video in `mp4` or `avi`
- Optimize for complete rubric coverage and maximum score, not only formatting.
